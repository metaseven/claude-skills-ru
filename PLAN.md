# План: русскоязычный каталог скилов Claude

Цель: сервис, где можно читать, фильтровать и искать скилы Claude на русском и быстро находить нужный, без ручного перевода.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Формат | Статический сайт (без бэкенда) |
| Хостинг | GitHub Pages (публичный репозиторий) |
| Перевод | Бесплатно: локально через субагентов Claude Code (Haiku/Sonnet, по подписке) и/или локальные модели Ollama. **Без оплаты Claude API** |
| Объём перевода | Описание + полный SKILL.md (с учётом лицензии скила) |
| Источники | anthropics/skills + 2–3 community-источника с первого этапа |
| Установка | Скачивание оригинала (английского скила) + инструкции по платформам |
| Контроль качества | Переводы попадают на сайт только после проверки (commit/PR) |

## Факты по исходному репозиторию (проверено 2026-10-24)

- В `anthropics/skills/skills/` всего **19 скилов**: academy-guide, algorithmic-art, brand-guidelines, canvas-design, claude-api, discernment-nudge, doc-coauthoring, docx, frontend-design, internal-comms, mcp-builder, pdf, pptx, skill-creator, slack-gif-creator, theme-factory, web-artifacts-builder, webapp-testing, xlsx.
- **docx, pdf, pptx, xlsx** — «© Anthropic, All rights reserved», использование по условиям Anthropic. Полный перевод не публикуем: только русское описание, пересказ «что делает / когда полезен» и ссылка на оригинал.
- Остальные (например, skill-creator) — Apache 2.0: перевод можно публиковать с указанием авторства и пометкой об изменениях.
- Вывод: одного официального репозитория мало для задачи «найти нужный скил» — нужны дополнительные источники.

## Архитектура

Перевод выполняется **локально** (бесплатно), CI только собирает и публикует сайт.

```
Источники скилов (anthropics/skills, community-репозитории)
        │
        ▼
 [локально, вручную] npm run sync ──► сканер безопасности + дифф (в data/ ничего не пишется)
        │
        ▼
 [человек] просмотр диффов и находок ──► npm run approve (привязка к хешу содержимого)
        │
        ▼
 [локально] /translate-skills в режиме перевода (хук блокирует всё, кроме записи переводов)
            или fallback: Ollama без инструментов
        │
        ▼
 npm run translate:end (только из терминала) ──► npm run validate ──► git push
        │
        ▼
 GitHub Actions: validate + zip из закреплённых коммитов + сборка ──► GitHub Pages
```

Автоматический сбор обновлений по расписанию **отключён** (решение от 2026-10-24): обновления запускаются вручную и всегда проходят проверку содержимого. Подробности о защите — в README, раздел «Защита».

## Перевод без оплаты API

### Вариант A (основной): субагенты Claude Code
- Работает в рамках подписки Claude (Pro/Max), отдельной оплаты за токены нет, но расходует лимиты подписки.
- В проекте: команда `/translate-skills` (`.claude/commands/`) и субагент `skill-translator` (`.claude/agents/skill-translator.md`, `model: haiku`).
- Главная сессия получает список изменённых скилов и запускает по субагенту на каждый (параллельно). Каждый субагент переводит один скил по правилам и глоссарию и записывает `SKILL.ru.md` + обновляет `meta.json`.
- Haiku — для описаний, тегов, категорий и коротких скилов; Sonnet — для длинных и сложных SKILL.md (модель указывается в определении субагента).
- Лучшее качество из бесплатных вариантов: хорошо держит Markdown, код и терминологию.

### Вариант B (fallback / массовый): локальные модели через Ollama
- Ollama уже установлен; машина — Apple M3 Max, 36 ГБ RAM.
- Установленные модели (`qwen2.5:7b`, `glm4`) слабоваты для качественного русского. Рекомендуется поставить модель покрупнее, помещающуюся в память: `gemma3:27b` или `qwen2.5:32b` (~17–20 ГБ в 4-бит). Выбор — по результатам сравнения на 3–5 скилах.
- Скрипт `npm run translate:local` переводит по частям (по разделам Markdown), блоки кода вырезаются перед переводом и вставляются обратно.
- Полностью бесплатно и офлайн, но качество ниже и медленнее — подходит для черновика или для большого числа community-скилов.

### Общие правила перевода (для обоих вариантов)
- Не переводить: блоки кода, inline-код, имена файлов, команды, YAML-ключи, `name` скила, URL.
- Глоссарий терминов (`data/glossary.json`): skill, agent, prompt, MCP, artifact и т.д.
- Проверка после перевода: количество блоков кода и ссылок совпадает с оригиналом, frontmatter валиден.

## Стек

| Слой | Выбор | Почему |
|---|---|---|
| Сайт | Astro (контент-коллекции) | Статика, отдельная страница на скил, SEO. В `astro.config` задать `site` и `base: '/<имя-репо>'` |
| Поиск | Pagefind | Полнотекстовый поиск по-русски в браузере, без сервера |
| Фильтры | Клиентский JS (категория, источник, лицензия, теги) | Достаточно для десятков–сотен скилов |
| Перевод | Субагенты Claude Code / Ollama | Без оплаты API |
| Автоматизация | GitHub Actions: только деплой на push; обновление источников — вручную | LLM в CI не вызывается, непроверенный контент в CI не попадает |
| Хостинг | GitHub Pages | Уже есть аккаунт, бесплатно для публичных репозиториев |

## Структура данных

```
data/
  sources.json        # список источников скилов (репо, путь, ветка)
  glossary.json       # глоссарий и список того, что НЕ переводить
  skills/<source>/<slug>/
    meta.json         # name, описание EN/RU, «что делает / когда полезен / пример запроса»,
                      # категория, теги, лицензия, ссылка на оригинал, хеш исходника, модель перевода
    SKILL.en.md       # оригинал (кэш)
    SKILL.ru.md       # перевод (только для разрешающих лицензий)
```

Хеш исходника в `meta.json`: если оригинал не изменился — повторный перевод не делается.

## Шаги

### Этап 0. Разведка
- Изучить структуру `anthropics/skills`: frontmatter, сопутствующие файлы (`reference.md` и т.п.), `marketplace.json`.
- Выбрать 2–3 community-источника, проверить их формат и лицензии.
- Сравнить качество перевода на 3–5 скилах: субагент Haiku vs Sonnet vs локальная модель Ollama.

### Этап 1. Конвейер данных
1. `npm run sync`: клонирует источники, парсит скилы, определяет лицензию, считает хеши, выводит список изменённых.
2. Глоссарий и правила перевода.
3. Субагент `skill-translator` + команда `/translate-skills` (вариант A).
4. Скрипт `translate:local` через Ollama (вариант B).
5. Генерация русского блока «Что делает / Когда полезен / Пример запроса», категорий и тегов — тем же субагентом.
6. Валидатор перевода (код, ссылки, frontmatter).

### Этап 2. Сайт (MVP)
1. Главная: карточки (название, русское описание, категория, источник, лицензия).
2. Поиск и фильтры.
3. Страница скила: блок «Что делает / Когда полезен», русский текст (если лицензия позволяет), переключатель RU/EN, ссылка на оригинал.
4. Установка: скачать zip оригинала + инструкции для claude.ai (загрузка), Claude Code (`/plugin marketplace add anthropics/skills`), API.

### Этап 3. Автоматизация и релиз
- Workflow деплоя на GitHub Pages при push в `main`.
- ~~Еженедельный workflow проверки источников~~ — отключён по соображениям безопасности, обновления вручную.
- Страница «О проекте»: неофициальный перевод, машинный перевод, авторство и лицензии.

### Этап 4. Позже (опционально)
- Кнопка «Предложить исправление перевода» (ссылка на редактирование файла в GitHub → PR).
- Больше источников, RSS или Telegram-канал с новыми скилами.
- Другие языки.

## Риски

- **Качество перевода.** Глоссарий, защита блоков кода, валидатор, ручная проверка перед публикацией.
- **Лицензии.** Публикуем полный перевод только для разрешающих лицензий; для остальных — описание и ссылка.
- **Лимиты подписки Claude.** Перевод всех скилов разом может упереться в лимиты; переводить партиями или использовать Ollama для черновиков.
- **Ручной шаг.** Обновление и перевод запускаются вручную; напоминаний из CI нет.
- **Вредоносные скилы (prompt injection, исполнение кода, symlink, XSS).** Закрыто: безопасный парсер frontmatter, сканер, ручное одобрение по хешу, режим перевода с хуком, проверка переводов, жёсткий CI. Тесты атак — 43 сценария + XSS.
