# Slack GIF Creator

Набор утилит и знаний для создания анимированных GIF, оптимизированных для Slack.

## Требования Slack

**Размеры:**
- GIF-эмодзи: 128x128 (рекомендуется)
- GIF для сообщений: 480x480

**Параметры:**
- FPS: 10–30 (чем ниже, тем меньше размер файла)
- Цвета: 48–128 (чем меньше, тем меньше размер файла)
- Длительность: для GIF-эмодзи держи меньше 3 секунд

## Основной процесс

```python
from core.gif_builder import GIFBuilder
from PIL import Image, ImageDraw

# 1. Create builder
builder = GIFBuilder(width=128, height=128, fps=10)

# 2. Generate frames
for i in range(12):
    frame = Image.new('RGB', (128, 128), (240, 248, 255))
    draw = ImageDraw.Draw(frame)

    # Draw your animation using PIL primitives
    # (circles, polygons, lines, etc.)

    builder.add_frame(frame)

# 3. Save with optimization
builder.save('output.gif', num_colors=48, optimize_for_emoji=True)
```

## Рисование графики

### Работа с изображениями, загруженными пользователем
Если пользователь загрузил изображение, выясни, что он хочет:
- **Использовать его напрямую** (например, «анимируй это», «разбей это на кадры»)
- **Использовать как вдохновение** (например, «сделай что-то похожее на это»)

Загружай и обрабатывай изображения через PIL:
```python
from PIL import Image

uploaded = Image.open('file.png')
# Use directly, or just as reference for colors/style
```

### Рисование с нуля
Когда рисуешь графику с нуля, используй примитивы PIL ImageDraw:

```python
from PIL import ImageDraw

draw = ImageDraw.Draw(frame)

# Circles/ovals
draw.ellipse([x1, y1, x2, y2], fill=(r, g, b), outline=(r, g, b), width=3)

# Stars, triangles, any polygon
points = [(x1, y1), (x2, y2), (x3, y3), ...]
draw.polygon(points, fill=(r, g, b), outline=(r, g, b), width=3)

# Lines
draw.line([(x1, y1), (x2, y2)], fill=(r, g, b), width=5)

# Rectangles
draw.rectangle([x1, y1, x2, y2], fill=(r, g, b), outline=(r, g, b), width=3)
```

**Не используй:** шрифты-эмодзи (они ненадёжно работают на разных платформах) и не предполагай, что в этом скиле есть готовая графика.

### Как сделать графику красивой

Графика должна выглядеть аккуратно и творчески, а не примитивно. Вот как этого добиться:

**Используй более толстые линии** — всегда задавай `width=2` или больше для контуров и линий. Тонкие линии (width=1) выглядят рваными и любительскими.

**Добавляй визуальную глубину**:
- Используй градиенты для фонов (`create_gradient_background`)
- Накладывай несколько фигур для сложности (например, звезду с меньшей звездой внутри)

**Делай фигуры интереснее**:
- Не рисуй просто круг — добавь блики, кольца или узоры
- У звёзд могут быть свечения (нарисуй под ними большие полупрозрачные версии)
- Комбинируй несколько фигур (звёзды + искры, круги + кольца)

**Внимательно подбирай цвета**:
- Используй яркие, дополняющие друг друга цвета
- Добавляй контраст (тёмные контуры у светлых фигур, светлые контуры у тёмных)
- Учитывай общую композицию

**Для сложных фигур** (сердца, снежинки и т.п.):
- Используй комбинации полигонов и эллипсов
- Тщательно рассчитывай точки для симметрии
- Добавляй детали (у сердца может быть светлая дуга-блик, у снежинок — сложные ветви)

Будь творческим и детальным! Хороший GIF для Slack должен выглядеть аккуратно, а не как заглушка.

## Доступные утилиты

### GIFBuilder (`core.gif_builder`)
Собирает кадры и оптимизирует их для Slack:
```python
builder = GIFBuilder(width=128, height=128, fps=10)
builder.add_frame(frame)  # Add PIL Image
builder.add_frames(frames)  # Add list of frames
builder.save('out.gif', num_colors=48, optimize_for_emoji=True, remove_duplicates=True)
```

### Валидаторы (`core.validators`)
Проверяют, соответствует ли GIF требованиям Slack:
```python
from core.validators import validate_gif, is_slack_ready

# Detailed validation
passes, info = validate_gif('my.gif', is_emoji=True, verbose=True)

# Quick check
if is_slack_ready('my.gif'):
    print("Ready!")
```

### Функции плавности (`core.easing`)
Плавное движение вместо линейного:
```python
from core.easing import interpolate

# Progress from 0.0 to 1.0
t = i / (num_frames - 1)

# Apply easing
y = interpolate(start=0, end=400, t=t, easing='ease_out')

# Available: linear, ease_in, ease_out, ease_in_out,
#           bounce_out, elastic_out, back_out
```

### Помощники для кадров (`core.frame_composer`)
Удобные функции для типичных задач:
```python
from core.frame_composer import (
    create_blank_frame,         # Solid color background
    create_gradient_background,  # Vertical gradient
    draw_circle,                # Helper for circles
    draw_text,                  # Simple text rendering
    draw_star                   # 5-pointed star
)
```

## Концепции анимации

### Тряска / вибрация
Смещай объект колебательным движением:
- Используй `math.sin()` или `math.cos()` с индексом кадра
- Добавляй небольшие случайные отклонения для естественности
- Применяй к координатам x и/или y

### Пульсация / сердцебиение
Ритмично меняй размер объекта:
- Используй `math.sin(t * frequency * 2 * math.pi)` для плавной пульсации
- Для сердцебиения: два быстрых удара, затем пауза (подправь синусоиду)
- Масштабируй между 0.8 и 1.2 от базового размера

### Прыжок
Объект падает и отскакивает:
- Используй `interpolate()` с `easing='bounce_out'` для приземления
- Используй `easing='ease_in'` для падения (с ускорением)
- Применяй гравитацию, увеличивая вертикальную скорость на каждом кадре

### Вращение
Вращай объект вокруг центра:
- В PIL: `image.rotate(angle, resample=Image.BICUBIC)`
- Для покачивания: используй синусоиду для угла вместо линейного изменения

### Появление / исчезновение
Постепенно появляйся или исчезай:
- Создай RGBA-изображение и меняй канал альфа
- Или используй `Image.blend(image1, image2, alpha)`
- Появление: альфа от 0 до 1
- Исчезновение: альфа от 1 до 0

### Выезд
Перемещай объект из-за границы кадра на место:
- Начальная позиция: за пределами кадра
- Конечная позиция: целевая точка
- Используй `interpolate()` с `easing='ease_out'` для плавной остановки
- Для перелёта с откатом: используй `easing='back_out'`

### Зум
Масштабируй и позиционируй для эффекта приближения:
- Приближение: масштаб от 0.1 до 2.0, обрезка по центру
- Отдаление: масштаб от 2.0 до 1.0
- Для драматичности можно добавить размытие в движении (фильтр PIL)

### Взрыв / разлёт частиц
Создавай частицы, разлетающиеся от центра:
- Генерируй частицы со случайными углами и скоростями
- Обновляй каждую частицу: `x += vx`, `y += vy`
- Добавляй гравитацию: `vy += gravity_constant`
- Постепенно скрывай частицы (уменьшай альфа)

## Стратегии оптимизации

Только если пользователь просит уменьшить размер файла, примени несколько из следующих методов:

1. **Меньше кадров** — ниже FPS (10 вместо 20) или короче длительность
2. **Меньше цветов** — `num_colors=48` вместо 128
3. **Меньшие размеры** — 128x128 вместо 480x480
4. **Удаление дубликатов** — `remove_duplicates=True` в save()
5. **Режим эмодзи** — `optimize_for_emoji=True` автоматически оптимизирует

```python
# Maximum optimization for emoji
builder.save(
    'emoji.gif',
    num_colors=48,
    optimize_for_emoji=True,
    remove_duplicates=True
)
```
