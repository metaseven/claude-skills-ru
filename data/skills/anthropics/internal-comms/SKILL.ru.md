## Когда использовать этот скил
Чтобы написать внутренние коммуникации, используй этот скил для:
- 3P-обновлений (Progress, Plans, Problems)
- корпоративных рассылок
- ответов на FAQ
- отчётов о статусе
- обновлений для руководства
- обновлений по проектам
- отчётов об инцидентах

## Как использовать этот скил

Чтобы написать любую внутреннюю коммуникацию:

1. **Определи тип коммуникации** по запросу
2. **Загрузи подходящий файл с инструкциями** из каталога `examples/`:
    - `examples/3p-updates.md` — для командных обновлений Progress/Plans/Problems
    - `examples/company-newsletter.md` — для корпоративных рассылок для всей компании
    - `examples/faq-answers.md` — для ответов на частые вопросы
    - `examples/general-comms.md` — для всего остального, что не соответствует явно ни одному из перечисленных выше типов
3. **Следуй конкретным инструкциям** из этого файла по формату, тону и сбору содержимого

Если тип коммуникации не соответствует ни одной существующей инструкции, попроси уточнить задачу или дать больше контекста о нужном формате.
