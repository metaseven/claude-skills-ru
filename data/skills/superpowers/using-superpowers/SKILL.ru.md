## Правило

**Вызывай подходящие или запрошенные скилы ДО любого ответа или действия** — включая уточняющие вопросы, исследование кодовой базы и проверку файлов. Если скил оказался неподходящим для ситуации, его можно не использовать.

**Перед входом в режим планирования:** если ты ещё не провёл брейнсторминг, сначала вызови скил брейнсторминга.

Затем объяви «Использую [скил], чтобы [цель]» и строго следуй скилу. Если в нём есть чек-лист, создай задачу на каждый пункт.

## Приоритет скилов

Когда подходят несколько скилов, сначала идут процессные скилы — они задают подход, а затем реализационные скилы (frontend-design и т.п.) выполняют работу. Брейнсторминг и systematic-debugging — самые частые процессные скилы Superpowers, но правило действует для любого из них.

- «Давай сделаем X» → сначала superpowers:brainstorming, затем реализационные скилы.
- «Исправь этот баг» → сначала superpowers:systematic-debugging, затем доменные скилы.

## Красные флаги

Эти мысли означают СТОП — ты рационализируешь:

| Мысль | Реальность |
|-------|------------|
| «Это просто простой вопрос» | Вопросы — тоже задачи. Проверь наличие скилов. |
| «Сначала нужно больше контекста» | Проверка скилов идёт ДО уточняющих вопросов. |
| «Сначала изучу кодовую базу» | Скилы подсказывают, КАК её изучать. Сначала проверь. |
| «Могу быстро проверить git/файлы» | Файлы не содержат контекста разговора. Проверь наличие скилов. |
| «Сначала соберу информацию» | Скилы подсказывают, КАК собирать информацию. |
| «Здесь не нужен формальный скил» | Если скил существует, используй его. |
| «Я помню этот скил» | Скилы меняются. Прочитай актуальную версию. |
| «Это не считается задачей» | Действие = задача. Проверь наличие скилов. |
| «Скил избыточен» | Простые вещи становятся сложными. Используй его. |
| «Сначала сделаю одну вещь» | Проверяй ДО любого действия. |
| «Это выглядит продуктивно» | Неорганизованные действия тратят время. Скилы этому мешают. |
| «Я знаю, что это значит» | Знать концепцию ≠ использовать скил. Вызови его. |

## Инструкции пользователя

Инструкции пользователя (CLAUDE.md, AGENTS.md, GEMINI.md и т.п., прямые запросы) имеют приоритет над скилами, а скилы, в свою очередь, переопределяют поведение по умолчанию. Пропускай процессы скилов или инструкции только тогда, когда твой партнёр явно сказал это сделать.
