# Скилы Claude на русском

Статический каталог скилов Claude с русским переводом, поиском и фильтрами. Публикуется на GitHub Pages:
https://metaseven.github.io/claude-skills-ru/

Источники: [anthropics/skills](https://github.com/anthropics/skills) и [obra/superpowers](https://github.com/obra/superpowers) (список — в `data/sources.json`).

## Как это устроено

```
data/
  sources.json, categories.json, glossary.json
  approvals.json   ← какие версии скилов вы проверили и одобрили (по хешу всего содержимого)
  skills/<source>/<slug>/
    meta.json      ← факты об одобренной версии: лицензия, коммит, хеши
    SKILL.en.md    ← оригинал
    ru.json        ← перевод: название, описание, пересказ, категория, теги
    SKILL.ru.md    ← полный перевод (только Apache-2.0/MIT и не больше 60 КБ)
```

Автоматического сбора обновлений нет: источники обновляются только вручную, с проверкой содержимого.
GitHub Actions только собирает сайт из уже одобренных данных.

## Обновление скилов (вручную)

### 1. Скачать и проверить

```bash
npm run sync
```

Скачивает источники (без symlink-ов, хуков git и сабмодулей) и прогоняет новые и изменённые скилы через сканер (`scripts/scanner.mjs`). В `data/` при этом **ничего не попадает**. Для каждого скила выводится:

- ⛔ **блокировка** — символические ссылки, невидимые или bidi-символы Unicode, ESC-последовательности, исполняемый frontmatter (`---js`), слишком большой файл. Такой скил одобрить нельзя.
- ⚠️ **подозрительные места** — prompt injection («ignore previous instructions», «note to the translator», «перед переводом…»), `curl | sh`, обращения к `~/.ssh` и токенам, запись в `.zshrc`, автозапуск, сервисы для утечки данных, скрытые HTML-комментарии, base64-блоки, опасный HTML.
- дифф SKILL.md относительно прошлой одобренной версии: `.cache/review/<source>__<slug>.diff`.

### 2. Просмотреть и одобрить

Откройте диффы и находки. Одобряйте только то, чему доверяете:

```bash
npm run approve                          # список ожидающих
npm run approve -- superpowers/brainstorming anthropics/pdf
npm run approve -- --clean               # все, где сканер ничего не нашёл
```

Одобрение привязано к хешу всего содержимого скила (включая скрипты). Если файлы изменились после `sync`, одобрение будет отклонено.

### 3. Перевести

В Claude Code, открытом в этой папке:

```
/translate-skills
```

Команда включает **режим перевода**: хук `scripts/guard-hook.mjs` работает и для основной сессии, и для субагентов. В этом режиме можно только:
- читать файлы проекта;
- записывать `ru.json` и `SKILL.ru.md`;
- запускать проверочные команды.

Запись в другие файлы, сеть, MCP и чтение секретов блокируются, даже если текст скила «уговорит» модель. У субагента-переводчика нет Bash.

После перевода в **своём терминале** (Claude выключить режим не может):

```bash
npm run translate:end   # покажет все изменённые файлы; файлы вне переводов → отказ
npm run validate        # код и ссылки совпадают с оригиналом, в переводе нет нового подозрительного текста
git diff data/skills
git add -A && git commit -m "Обновление переводов" && git push
```

### Вариант без Claude: Ollama

```bash
ollama pull gemma3:27b
npm run translate:local
```

У локальной модели нет инструментов, и она работает только с `localhost`. Инъекция может испортить только текст перевода, а это ловит `npm run validate`.

## Защита: что и от чего

| Угроза | Защита |
|---|---|
| Исполнение кода из frontmatter (`---js`, YAML-теги) | Свой парсер: только `---` + безопасная схема YAML, плоские значения |
| Symlink на `~/.ssh` и т.п. | Клон с `core.symlinks=false`, сканер блокирует ссылки, архивы собираются с `zip -y` |
| Prompt injection в переводчика | Режим перевода с хуком, субагент без Bash, текст скила помечен как данные, ручное одобрение до перевода |
| Подмена перевода | `validate`: блоки кода и адреса ссылок совпадают с оригиналом, нет новых подозрительных мест, нет лишних файлов и полей |
| Непроверенный код в zip | Архив собирается из закреплённого коммита после сверки хеша с одобренным |
| XSS на сайте | HTML из Markdown экранируется, ссылки только http(s), картинки не загружаются, CSP |
| Подмена в CI | Actions закреплены по SHA, `npm ci --ignore-scripts`, минимальные права у каждой задачи, нет сбора обновлений по расписанию |
| Обман терминала | Вывод сканера очищается от ESC- и управляющих символов |

Сканер — это подсветка, а не гарантия. Главная защита — ручной просмотр диффа перед `approve` и запрет действий в режиме перевода.

## Локальный просмотр

```bash
npm run zips && npm run build && npm run preview
```

## Публикация

Каждый push в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`). Сборка падает, если `npm run validate` находит ошибку или скил без одобрения.

## Добавить источник

Добавьте запись в `data/sources.json`, затем `npm run sync` → просмотр → `npm run approve` → `/translate-skills`. Подключайте только репозитории, которым доверяете.
