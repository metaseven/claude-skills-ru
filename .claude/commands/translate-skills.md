---
description: Перевести на русский все новые и изменённые скилы с помощью субагентов skill-translator
argument-hint: "[source/slug ...]  (необязательно — только указанные скилы)"
---

Переведи скилы, которым нужен перевод.

1. Выполни `node scripts/status.mjs --json`. Если указаны аргументы ($ARGUMENTS) — оставь только эти id.
2. Если список пуст — сообщи, что всё актуально, и закончи.
3. Для каждого скила запусти субагента `skill-translator` с промптом: `Переведи скил в папке <dir>`.
   Запускай параллельно, партиями по 6 субагентов. Скилы больше 15 000 байт с `scope: "full"` запускай с `model: sonnet` — Haiku хуже справляется с длинными текстами.
4. Когда все закончат, выполни `node scripts/validate.mjs`. Скилы с ошибками отправь тому же субагенту ещё раз с текстом ошибки (не более 2 попыток).
5. Выведи итоговую таблицу: переведено / с предупреждениями / с ошибками. Не коммить — пользователь сначала проверяет перевод.
